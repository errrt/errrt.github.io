Open the launcher before typing a search, and phrases you use often on the current site appear near the top. The same library can have a different order on different sites.

02 / How it works

Save a snippet.
Insert it when you need it.

  1. Save your wording

    Add text you want to reuse and give it a shortcut, such as ;follow.

  2. Use a shortcut or search

    Type the shortcut and press Space or Enter. Or press Command/Ctrl + Shift + K to open the launcher and search.

  3. Review, then insert

    Add fields such as {{name}} or {{company}}. Review the values and preview before inserting. Suggestions are not selected automatically.

PhraseCrate inserts the phrase you confirm. It never sends your message.

06 / Questions

Before you start.

How is this different from a basic text snippet list?

Before you search, the launcher puts phrases you use often on the current website near the top. You can still search by name, shortcut, or phrase text.

Does PhraseCrate write replies with AI?

No. It inserts wording you save and confirm. It does not generate replies or send your messages.

Does it work in every website editor?

It works with standard text fields, text areas, and common content-editable fields. Some custom editors have limited support. Chrome internal pages and the Chrome Web Store do not allow insertion by extensions. Reload your intended page after installing the extension.

Can I sync my snippets across devices?

There is no cloud sync. You can export and import phrases with a JSON backup. Pro's three-device license does not sync your data.

Can I install it on my phone?

PhraseCrate is for desktop Chrome. A mobile-friendly website does not mean the extension runs in mobile Chrome.
