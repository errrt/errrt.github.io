Use the templates in Chrome

  1. Install PhraseCrate

    Open the extension and select Enable PhraseCrate.

  2. Import the JSON

    Download the file above and select Import backup in PhraseCrate. If you already use PhraseCrate, export a backup first. Import adds phrases and skips shortcuts you already use.

  3. Insert a reply

    Reload your writing tab after installing. Type ;bug in a text field and press Space. Fill in the fields, review the text, and choose Insert.

Receiving a request

Request received ;received

Acknowledge a request when you still need to look into it.

Hi {{name}},

Thanks for reaching out about {{issue}}. I’m looking into it and will send an update by {{next_update}}. If anything changes on your end before then, feel free to reply here.

Request more details ;details

Ask for one specific detail that will help you move forward.

Hi {{name}},

I can help with this. Could you tell me {{detail_needed}}? That will help me narrow down what’s happening. Please leave out passwords and other sensitive details.

Follow up on an open request ;followup

Ask whether an issue is still happening after sharing a next step.

Hi {{name}},

I’m checking in about {{issue}}. Were you able to try {{suggested_step}}? If you’re still blocked, let me know what happens and I’ll pick up from there.

Troubleshooting

Ask for bug reproduction steps ;bug

Turn a bug report into enough information to reproduce the issue.

Hi {{name}},

Thanks for reporting this. Could you send the steps that led to {{issue}}, what you expected to happen, and your browser and version? If you include a screenshot, please hide any customer data or credentials.

Share a workaround ;workaround

Give the customer a way to keep working while you investigate.

Hi {{name}},

While I investigate {{issue}}, you can try this workaround: {{workaround}}. If it doesn’t work for your setup, let me know where it stops so I can suggest another option.

Confirm a fix ;fixed

Let a customer know a verified fix is available and how to check it.

Hi {{name}},

The fix for {{issue}} is now available. Please {{verification_step}} to check it on your end. If you still see the problem, reply with what happened and I’ll take another look.

Billing and access

Clarify a billing charge ;billing

Explain what a charge covers after checking the invoice.

Hi {{name}},

I checked invoice {{invoice_number}}. The charge covers {{billing_reason}}. If this is a different charge from the one you’re asking about, send the charge date and amount. Please don’t send your card number.

Acknowledge a refund request ;refund

Confirm receipt of a refund request before making a decision.

Hi {{name}},

I received your refund request for {{order_reference}}. I’ll check it and get back to you by {{next_update}} with the outcome or the next step.

Help with a sign-in problem ;signin

Direct a customer to the appropriate sign-in recovery step.

Hi {{name}},

To recover access, please start with {{recovery_step}}. If that doesn’t work, tell me the error message and which step showed it. Please don’t send passwords, reset links, or verification codes.

Product feedback and closure

Acknowledge a feature request ;feature

Understand the workflow behind a request without promising a release.

Hi {{name}},

Thanks for suggesting {{feature}}. What are you trying to accomplish when you need it, and how do you handle that today? That context will help me understand where the current workflow falls short.

Share a progress update ;progress

Keep a customer informed when an investigation is still open.

Hi {{name}},

A quick update on {{issue}}: {{current_status}}. My next step is {{next_step}}, and I’ll update you again by {{next_update}}.

Close a resolved request ;resolved

Summarize the outcome and tell the customer how to reopen the conversation.

Hi {{name}},

I’m closing this request after {{resolution}}. If the issue comes back or you have a question about the fix, reply here and I’ll have the context to help.
